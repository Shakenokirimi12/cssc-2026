# ブロック崩しゲーム

このプロジェクトは、CreateJS を使って作られたシンプルなブロック崩しゲームです。

## 概要
- スペースキーでゲーム開始
- 左右矢印キーでバーを動かす
- 1〜5キーでステージを切り替えられる
- Mキーでミュート切り替えができる

## 実行方法
1. このフォルダを開く
2. index.html をブラウザで開く
3. スペースキーでスタートする

## 操作方法
- スペースキー: ゲーム開始 / ボール発射
- ← / →: パドル移動
- 1〜5: ステージ切り替え
- M: ミュート切り替え

## ファイル構成
- index.html: ゲーム画面の読み込み
- global.js: ゲーム設定・ステージ定義
- init.js: 初期化処理
- key.js: キー入力処理
- tick.js: メインループ・当たり判定
- student.js: 学習用の関数実装
- material/: 画像・音声素材

## 補足
global.js の設定を変えることで、ブロックの配置やボールの速度などを簡単にカスタマイズできます。
student.jsの関数を変えることで、関数の役割を確認します。
