# CreateJS 横スクロールゲーム教材

プログラミング未経験の高校生が、**最初から遊べるゲームを少しずつ改造し、「自分でゲームを変えられた」と実感すること**を目的にした教材です。

募集要項の高校1～3年生向けJavaScriptゲームプログラミングコースと、CSSC2026のCreateJS教材の構成を踏まえ、約10時間のゲーム制作用に再構成しています。

## まずゲームを遊ぶ

1. このフォルダを開く
2. `index.html` をダブルクリックする
3. ブラウザでゲームが始まる

操作は次のとおりです。

| 操作 | キー |
|---|---|
| 左右移動 | `←` `→` または `A` `D` |
| ジャンプ | `↑` `W` `Space` |
| 最初からやり直す | `R` |
| 音のON/OFF | `M` |

通常は公式CreateJS 1.0.0を読み込みます。ネット接続が使えない場合は、教材内の簡易互換版へ自動で切り替わるため、ゲーム自体は遊べます。

## 生徒が編集するファイル

### 1日目：`settings.js`

数字、色、敵、コイン、床などを変更します。

変更しやすい項目：

- プレイヤーの移動速度
- ジャンプ力と重力
- プレイヤー・敵・背景の色
- 制限時間と残機
- コイン・敵・ゴールの得点
- 敵の数と移動速度
- コインの数と位置
- 足場、穴、トゲの位置
- BGMの速さ
- PNG画像への変更

### 2日目：`student.js`

小さな機能を一つ追加します。

- コインをすべて取るとクリア
- 特定エリアでメッセージを表示
- 敵によって得点を変える
- アイテムで一定時間スピードアップ
- ボタンで扉を開く

ゲームの複雑な処理は `game.js` にまとめてあります。最初は編集しません。

## ファイル構成

| ファイル | 役割 | 生徒が編集するか |
|---|---|---|
| `index.html` | ゲーム画面とファイル読み込み | 編集しない |
| `settings.js` | 数字・色・ステージ配置 | 1日目に編集 |
| `student.js` | 条件と機能追加 | 2日目に編集 |
| `game.js` | 横スクロールゲーム本体 | 原則編集しない |
| `createjs-fallback.js` | オフライン時の簡易互換処理 | 編集しない |
| `生徒用_改造ガイド.md` | 最初の改造手順 | 配布用 |
| `INSTRUCTOR_GUIDE.md` | 10時間の授業進行と機能追加手順 | 講師用 |
| `企画シート.md` | オリジナル制作前の記入用紙 | 配布用 |

## 保存しても変化しない場合

1. `Ctrl + S` で保存したか確認する
2. ブラウザで `Ctrl + R` を押す
3. 画面下部に赤いエラー欄が出ていないか確認する
4. カンマ `,`、ダブルクォート `"`、中カッコ `{ }` の不足を確認する

エラーがあっても、壊れた場所と行番号の目安をゲーム画面に表示します。

## 講師向けの確認

授業開始前に、各PCで次を確認してください。

- `index.html` が開く
- 右へ移動し、ジャンプできる
- `settings.js` の `playerMoveSpeed` を変更すると速さが変わる
- VS Codeでファイルを保存できる
- ブラウザの再読み込みができる
- 音量が大きすぎない
