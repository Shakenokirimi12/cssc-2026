# CreateJS 3Dアクション デモ

授業の最後に「学習を進めると、こんなゲームも作れるようになる」と見せるための短い完成例です。

## 起動方法

1. フォルダ内の `index.html` をダブルクリックします。
2. ブラウザでゲームが始まります。
3. インターネットにつながらない場合も、同梱の `createjs-fallback.js` で動作します。

## 操作

| 操作 | キー |
|---|---|
| 前後左右に移動 | WASD または矢印キー |
| ジャンプ | SPACE |
| ダッシュ | SHIFTを押しながら移動 |
| やり直し | R |

## ゲーム内容

- 穴をジャンプで越える
- 敵を上から踏みつける
- 敵に横から触れるとスタートへ戻る
- 黄色い旗に触れるとゴール

## 3Dに見える仕組み

CreateJSは基本的に2D Canvasを扱うライブラリです。この作品では、ゲーム内の物体を `x・y・z` の3D座標で管理し、カメラから見た位置を計算して2D画面へ投影しています。

つまり、立方体の頂点を3D空間で作り、それぞれを画面上の座標へ変換して、CreateJSの `Shape` で面を描いています。

## 授業で改造しやすい場所

`settings.js` を編集します。

- `moveSpeed`：移動速度
- `dashMultiplier`：ダッシュ倍率
- `jumpPower`：ジャンプ力
- `gravity`：重力
- `colors`：色
- `platforms`：足場
- `enemies`：敵
- `goal`：旗の位置

## 主なファイル

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム画面とCreateJSの読み込み |
| `settings.js` | 生徒や先生が変更しやすい設定 |
| `game.js` | 3D投影、移動、ジャンプ、ダッシュ、敵、ゴール |
| `createjs-fallback.js` | オフライン用の簡易CreateJS互換版 |
| `授業用_見せ方.md` | 授業の最後での紹介例 |

## 注意

本格的な3Dゲームエンジンではなく、CreateJS上で3D座標と遠近法を自作した「簡易3Dデモ」です。授業用として、短時間で仕組みと完成イメージを見せることを優先しています。
