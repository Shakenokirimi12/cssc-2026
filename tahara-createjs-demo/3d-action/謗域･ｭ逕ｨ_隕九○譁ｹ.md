# 授業の最後での見せ方

## 1. 最初にプレイする

先生が30秒ほど操作します。

1. 普通に移動する
2. ジャンプで穴を越える
3. SHIFTでダッシュする
4. 敵を上から踏む
5. 旗に触れてゴールする

## 2. 生徒への説明例

> 今日学んだ変数、条件分岐、繰り返し、座標の考え方を組み合わせると、こうしたゲームも作れるようになります。
>
> このゲームは、プレイヤーや敵をx・y・zの3つの数字で動かしています。画面は平面ですが、計算によって奥行きのある見た目にしています。

## 3. コードを少し見せる

`settings.js` を開き、次のどれか1つだけ変更します。

- `jumpPower: 11.5` を `16` にする
- `dashMultiplier: 2.15` を `3` にする
- `player` の色を変える
- 敵を1体コピーして増やす

保存してブラウザを再読み込みし、ゲームの変化を見せます。

## 4. 伝えたいポイント

- ゲームは小さな処理の組み合わせでできている
- 数字を変えるだけでも遊びは変わる
- 2D用のCreateJSでも、数学を使えば立体表現に挑戦できる
- 完成品を最初から作るのではなく、移動、ジャンプ、敵、ゴールの順に追加していく
