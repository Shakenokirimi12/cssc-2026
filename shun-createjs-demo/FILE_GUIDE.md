# STAR & BOMB CATCH：ファイル別 解説ガイド

この文書は、ゲームのコードを「どのファイルが何を担当しているか」という視点で読むための解説書です。コードを書き換える前に、一度目を通しておくと迷いにくくなります。

## 最初に知っておきたい言葉

- **Canvas**：ゲームの絵を表示する場所。`index.html` の `<canvas>` がこれに当たります。
- **Stage（ステージ）**：Canvasの上に、図形や文字を置くCreateJSの舞台です。
- **Ticker（ティッカー）**：1秒に約60回、ゲームを更新する仕組みです。
- **変数**：点数やプレイヤーの位置など、途中で変わるデータを入れておく箱です。
- **関数**：何度も使う処理を、名前を付けてまとめたものです。

## ファイルのつながり

`index.html` が各JavaScriptファイルを読み込みます。ゲームが始まると、次のように役割分担します。

1. `global.js` が設定値と共有する変数を用意する。
2. `init.js` がStage・背景・プレイヤー・UIを作り、イベントを登録する。
3. `key.js` と `mouse.js` が操作を受け取る。
4. `tick.js` が毎フレーム、移動・落下・当たり判定・表示更新を行う。
5. `gameover.js` が爆弾・時間切れの終了画面を表示する。
6. `student.js` は、生徒が独自の機能を追加するための入口になる。

## `index.html`：ゲームを開くための入口

### 役割

ブラウザが最初に読むファイルです。ゲーム画面のCanvas、ページ上部のタイトル、操作説明を置き、CreateJSと各JavaScriptファイルを読み込みます。

### 大事な部分

- `<canvas id="myCanvas" width="600" height="600">`：ゲームを描く場所です。`id="myCanvas"` は、`init.js` がStageを作るときに使います。
- `<script src="https://code.createjs.com/...">`：CreateJS本体を読み込みます。ここが読み込めないとゲームは動きません。
- `<script src="global.js">` から始まる部分：各ファイルを読む順番です。設定を最初に読み込み、最後に初期化を行う順に並んでいます。
- `<style>`：ページ全体の色、Canvasの枠線、文字の見た目を決めます。

### 変更してよい例

- `<h1>` の文字を自分のゲーム名にする。
- `body` の `background` を変えて、ゲームの外側のページ色を変える。
- Canvasの `width` と `height` を変える。ただし、変える場合は `global.js` の `STAGE_W` と `STAGE_H` も同じ数値にそろえます。

### 注意

JavaScriptファイルの読み込み順は、基本的に変えません。たとえば、設定を持つ `global.js` を後ろへ移動すると、ほかのファイルが変数を使えなくなることがあります。

## `global.js`：設定値とゲーム全体のデータ置き場

### 役割

「ゲームをどういう遊び心地にするか」を決める数字・色・ファイル名を集めたファイルです。高校生が最初に改造する場所です。

### 前半：変更しやすい設定

| まとまり | 主な変数 | 意味 |
| --- | --- | --- |
| 画面 | `STAGE_W`, `STAGE_H` | ゲーム画面の大きさ |
| プレイヤー | `playerMoveSpeed`, `playerWidth` | バスケットの速さ・大きさ |
| 落ち物 | `itemSpawnInterval`, `starProbability` | 出現の多さ・星の出やすさ |
| 得点 | `starScore` | 星1個の基本点 |
| 時間 | `timeLimitSeconds` | ゲーム時間 |
| 終盤 | `hurryUpSeconds`, `hurryUpSpeedMultiplier` | 何秒前から、何倍速にするか |
| コンボ | `comboContinueMilliseconds` | 次の星までに許される時間 |
| 素材 | `useMaterialImages`, `useSoundEffects` | 自作画像・効果音を使うか |

### 後半：ゲーム本体が使う共有変数

`stage`、`player`、`score`、`itemList` などは、複数のファイルから使うデータです。たとえば、`key.js` は左右キーが押されたことを `isPressLeft` に記録し、`tick.js` はその値を見て `player.x` を動かします。

### 変更してよい例

- `playerMoveSpeed = 8` を `14` にする：プレイヤーが速くなる。
- `itemSpawnInterval = 700` を `450` にする：落ち物が増える。
- `starProbability = 0.78` を `0.9` にする：爆弾が減って簡単になる。
- `timeLimitSeconds = 30` を `45` にする：長く遊べる。
- `playerColor` を `"#ff66aa"` にする：バスケットの色が変わる。

### 注意

後半の共有変数はゲームの途中で書き換わります。最初は前半の「★」が付いた設定だけを変えるのがおすすめです。

## `init.js`：ゲームの準備と画面づくり

### 役割

ゲームを開いた直後や、ゲームを最初から作り直すときに必要な準備をするファイルです。Stageの作成、キー・クリック・Tickerの登録、背景・プレイヤー・文字の作成を担当します。

### 主な関数

| 関数 | すること |
| --- | --- |
| `init()` | Stageを作り、操作とTickerを登録する最初の関数 |
| `prepareMaterials()` | 自作画像を読み込む。失敗した画像は図形で代用する |
| `prepareSoundEffects()` | 効果音を鳴らす準備をする |
| `playSoundEffect()` | 指定した名前の効果音を鳴らす |
| `showTitleScreen()` | タイトル画面を表示する |
| `startGame()` | データをリセットして新しいゲームを開始する |
| `createGameScene()` | 背景・アイテム用レイヤー・UIを作る |
| `createPlayer()` | バスケットまたは自作画像のプレイヤーを作る |
| `createUserInterface()` | SCORE、TIME、COMBOの文字を作る |

### レイヤーとは

`itemLayer`、`effectLayer`、`uiLayer` は、絵を重ねる順番を整理するための箱です。下から順に「落ち物」「+10などの演出」「スコア表示」が置かれます。こうしておくと、スコア文字が星に隠れません。

### 素材があるときの動き

`useMaterialImages` が `true` の場合、`prepareMaterials()` が `material/player.png` などを読み込みます。画像を見つけられなかった場合はエラーで止めず、元の図形を表示します。

### 注意

`init()` はファイルを開いたときに一度だけ呼ばれます。ゲームをやり直すときは `init()` ではなく `startGame()` を使い、Tickerやイベントを何度も登録しないようにしています。

## `key.js`：キーボード操作を記録する

### 役割

キーボードの「押した」「離した」を見つけるファイルです。ここではプレイヤーを直接動かさず、`isPressLeft` と `isPressRight` というフラグを変えるだけにしています。

### 主な関数

- `handleKeyDown(e)`：キーを押したときに呼ばれます。
  - `←`、`A`：左フラグを `true` にする。
  - `→`、`D`：右フラグを `true` にする。
  - `SPACE`：タイトルや結果画面ならゲームを始める。
  - `R`：ゲームオーバーや時間切れならやり直す。
- `handleKeyUp(e)`：キーを離したときに呼ばれ、左右フラグを `false` に戻します。

### なぜ「フラグ」にするの？

キーが押されている間は、毎フレーム少しずつ動かしたいからです。`key.js` が「左を押している」と記録し、`tick.js` が毎フレームその記録を確認します。

### 注意

`e.preventDefault()` は、矢印キーを押したときにブラウザのページがスクロールするのを防ぐ処理です。消すと、ゲーム中にページが動くことがあります。

---

## `mouse.js`：クリックで開始する

### 役割

キーボードが使えない場合でも、Canvasをクリックしてスタート・リスタートできるようにするファイルです。

### 主な関数

`handleMouseDown(event)` は、Canvasがクリックされたときに呼ばれます。タイトル画面、ゲームオーバー画面、時間切れ画面なら `startGame()` を呼びます。

### 発展アイデア

将来、画面内に「スタートボタン」や「難易度選択ボタン」を置く場合は、`event.stageX` と `event.stageY` を使い、クリック位置がボタンの中かどうかを調べます。

## `tick.js`：ゲームを毎フレーム進める中心ファイル

### 役割

ゲーム中で最も大切なファイルです。`handleTick()` はTickerから1秒に約60回呼ばれます。ここで「今、何が起きているか」を毎回更新します。

### 1フレームの流れ

1. タイトル・終了画面なら、動かさずに画面を描く。
2. `updatePlayer()` でプレイヤーを左右へ動かす。
3. `updateTimer()` で残り時間と終盤演出を更新する。
4. `createItemWhenNeeded()` で、一定間隔ごとに星または爆弾を出す。
5. `updateItems()` で、すべての落ち物を動かして当たり判定をする。
6. `updateEffects()` で「+10」などの文字を少しずつ消す。
7. `updateUserInterface()` で得点・時間・コンボを文字に反映する。
8. `stage.update()` で画面を書き直す。

### 主な関数

| 関数 | すること |
| --- | --- |
| `updatePlayer()` | キーのフラグを見てプレイヤーを動かし、画面外へ出ないようにする |
| `updateTimer()` | 残り時間を計算し、最後の10秒にHURRY UPを始める |
| `createFallingItem()` | ランダムに星か爆弾を作る |
| `updateItems()` | 落ち物を下げ、当たり判定・取り逃しを処理する |
| `isHitPlayer()` | 円形のアイテムと長方形のプレイヤーが重なったか調べる |
| `catchStar()` | コンボ・得点・効果音・+得点表示を処理する |
| `resetCombo()` | 星を逃したときにコンボを戻す |
| `addFloatingText()` | 上に浮かんで消える文字を作る |

### コンボの考え方

星を取るたびに `comboCount` を1増やします。前の星から `comboContinueMilliseconds` 以上の時間が空いていたら、連続ではないので0から始めます。3個ごとに `comboMultiplier` が上がり、最終的な得点は `starScore × comboMultiplier` で計算します。

### 当たり判定の考え方

プレイヤーは長方形、星と爆弾は円として扱います。円の中心から長方形の一番近い点までの距離を計算し、その距離が半径より小さければ「当たった」と判断します。

### 変更してよい例

- `createFallingItem()` に新しいアイテムの種類を足す。
- `catchStar()` に、一定のコンボ数でボーナスを入れる。
- `resetCombo()` に、取り逃し時の減点を入れる。

### 注意

ここは1秒に約60回動くため、重い処理を入れすぎるとゲームが遅くなります。まずは、文字を出す・点数を変えるといった小さな改造から始めましょう。

## `gameover.js`：終了条件と結果画面

### 役割

爆弾に当たったときと、時間が0になったときの終了処理をまとめています。終了後にプレイヤーが動き続けないよう、左右キーのフラグもオフにします。

### 主な関数

- `gameOverByBomb()`：爆弾に当たったときのゲームオーバー。爆発音を鳴らし、赤い結果画面を出します。
- `gameOverByTime()`：時間切れの処理。TIME表示を0にして、黄色い結果画面を出します。
- `showResultScreen()`：黒い半透明のパネル、最終得点、再開方法を表示します。
- `showCenterMessage()`：タイトル画面の説明文を中央に表示します。

### なぜ `if (isGameOver || isTimeUp) return;` があるの？

終了した後もTicker自体は動いています。同じ終了処理を何度も実行しないように、すでに終わっていたら関数をすぐ終えるための安全装置です。

## `student.js`：自分のアイデアを追加する練習場所

### 役割

生徒がゲーム本体を大きく壊さず、オリジナル機能に挑戦するためのファイルです。`tick.js` から決まったタイミングで呼ばれます。

### 主な関数

- `studentOnCatchStar(item, gainedScore)`：星を取った直後に呼ばれます。
- `studentOnMissStar()`：星を取り逃した直後に呼ばれます。

### 例として入っているコード

- `score >= 100` のとき、"100点突破！" を表示する。
- 星を取ったとき、`player.scaleX` と `player.scaleY` を変えてプレイヤーを大きくする。
- 星を逃したとき、`score = Math.max(0, score - 5)` で5点減らす。

最初は、コメントの先頭にある `//` を1組だけ外して試します。複数を同時に変えるより、何が変わったか分かりやすくなります。

## `material/README.md`：素材フォルダの説明書

### 役割

自作画像・効果音を入れる `material` フォルダの使い方と、使用してよい素材の約束をまとめています。

### 使うファイル名

- 画像：`player.png`、`star.png`、`bomb.png`
- 効果音：`start.mp3`、`star.mp3`、`bomb.mp3`、`hurry.mp3`、`timeup.mp3`

素材を使うときは、`global.js` の `useMaterialImages` または `useSoundEffects` を `true` にします。ファイル名を変えた場合は、`global.js` に書かれたパスも同じように変更します。
