# material フォルダ

このフォルダは、自作・利用許可のある画像と効果音を入れる場所です。

## 画像

| ファイル名 | 使われる場所 |
| --- | --- |
| `player.png` | 操作するバスケット |
| `star.png` | 取ると得点になる星 |
| `bomb.png` | 当たるとゲームオーバーになる爆弾 |

画像を使うには、`global.js` の `useMaterialImages` を `true` にします。背景が透明なPNGがおすすめです。

## 効果音

| ファイル名 | 鳴るタイミング |
| --- | --- |
| `start.mp3` | スタート |
| `star.mp3` | 星を取ったとき |
| `bomb.mp3` | 爆弾に当たったとき |
| `hurry.mp3` | 残り10秒 |
| `timeup.mp3` | 時間切れ |

効果音を使うには、`global.js` の `useSoundEffects` を `true` にします。MP3のほか、WAVでも使えます。WAVにする場合は、`global.js` に書かれたファイル名も合わせて変更してください。

## 約束

- 自分で作った素材か、ゲームで使ってよいと明記された素材だけを使う。
- 素材の配布条件・クレジット表記の必要性を確認する。
- ファイル名を変えたら、`global.js` の設定も同じように変える。
